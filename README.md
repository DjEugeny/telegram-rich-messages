# Telegram Rich Messages

Личный сервис для подготовки и публикации постов в Telegram. Вы описываете задачу агенту обычными словами, смотрите результат и разрешаете публикацию. Агент работает с текстом, изображениями, видео, коллажами, слайд-шоу и цитатами; сервис сохраняет версии и историю.

Рабочий цикл: **материал → превью → правки → разрешение → публикация**.

Агент сам оформляет текст в Rich Markdown: заголовки и подзаголовки, списки, цитаты, таблицы и дополнительные подробности — по смыслу вашего материала. Отдельно просить форматирование не нужно. Текстовый пост без настоящего заголовка сервис к отправке не допускает.

## Начать с агентом

Передайте в новый чат ссылку:

[github.com/DjEugeny/telegram-rich-messages](https://github.com/DjEugeny/telegram-rich-messages)

И напишите:

> Помоги запустить сервис и провести первую настройку. Доступов ещё нет — проведи меня по шагам, включая Telegram.

Можно скачать проект через **Code → Download ZIP** и открыть распакованную папку в агентной среде. Либо клонировать:

```sh
git clone https://github.com/DjEugeny/telegram-rich-messages.git
```

Агент прочитает инструкции проекта, определит среду запуска и покажет подходящие вам шаги. Поддерживаются macOS и Windows; нужен Python 3.11 или новее. Установка дополнительных пакетов и ffmpeg не требуется. Для голосовых поручений используется голосовой ввод вашей агентной среды.

## Пример или свой пост

Можно посмотреть временную демонстрацию или сразу подготовить собственный материал.

**Демонстрация не добавляет посты в вашу личную историю.** Она работает отдельно, без Telegram и токена; после закрытия демонстрации можно начать с пустой рабочей истории. Удалять примеры вручную не нужно.

Для самостоятельного просмотра в папке проекта:

- macOS, Terminal: `python3 tool.py preview-demo`.
- Windows, PowerShell: `py -3 tool.py preview-demo`.

Откройте адрес, который напечатает команда. Остановить демонстрацию — `Ctrl+C`. Обычно эти действия выполняет агент.

## Первая настройка Telegram

Агент ведёт по одному шагу:

1. Подключите свой существующий канал. Новый можно создать, если вы сами выбрали этот вариант. Агент объяснит, где скопировать ссылку; её достаточно прислать целиком.
2. Независимо выберите существующего бота или создание нового через [BotFather](https://t.me/BotFather).
3. Добавьте бота администратором в выбранный канал с правом публикации.
4. Агент пошагово объяснит, как открыть своё окно Terminal/PowerShell, перейти в нужную папку и запустить скрытый ввод. Сохраните действующий токен; пришлите только итог «сохранён в защищённом хранилище».
5. Подготовьте материал и посмотрите превью.
6. После вашего разрешения агент опубликует согласованный пост. Проверьте результат в Telegram.

Если канал или бот уже есть, создавать замену не нужно. Даже когда бот уже администратор, его токен нужно сохранить в текущую установку сервиса. Если вы знаете, где взять токен, объяснение BotFather можно пропустить; инструкцию его скрытого ввода агент всё равно покажет. Публичная ссылка канала или целая ссылка на пост приватного канала разбирается системой автоматически. Подробные шаги — в [руководстве подключения Telegram](docs/TELEGRAM-SETUP.md). **Не присылайте токен в чат и не показывайте его на скриншоте.** При вводе в терминале символы скрыты — это нормально.

Наличие подключённого бота само по себе не разрешает отправку. Агент сначала показывает материал, выбранный канал и бота, затем получает разрешение публикации.

## Повседневная работа

Примеры поручений:

- «Подготовь пост из этого текста и файлов. Покажи превью».
- «Обложку первой, затем видео и две фотографии».
- «Последний абзац оформи цитатой».
- «Поменяй изображения местами».
- «Исправь опубликованный пост».
- «Покажи историю за месяц».

Команды, форматы данных и технические ID — работа агента. Дашборд служит для просмотра и истории. Изменения обсуждаются в чате с агентом. Локальное превью приблизительное: окончательный вид проверяется в Telegram.

## Свои материалы и данные

Рабочая история начинается пустой, пока вы не сохраните свой первый пост. Для открытия рабочего сервиса агент использует `serve`, а для примера — отдельный `preview-demo`.

Посты и версии сохраняются в `posts/`, копии медиа — в `media/`, состояние и подтверждения доставки — в `data/`. Для переноса сохраняйте эти папки вместе при остановленных операциях. На новом компьютере токен нужно ввести заново.

Данные, токены и локальные настройки не публикуются в Git. Токен хранится средствами macOS или Windows; после успешной отправки сам пост хранится в Telegram.

Изображения: PNG, baseline и progressive JPEG до 10 MiB. Видео: MP4 H.264/AVC с необязательным AAC до 50 MiB. Оригиналы копируются без перекодирования. Если формат не подходит, агент объяснит причину; скрытой конвертации нет.
