# ADR 0005. Rich Media, структурные inline и приблизительное превью

## Контекст

Четыре Telegram-референса требуют портретных фото, смешанной группы с видео, цитат, подчёркивания и различения Unicode/custom emoji. Требуется сохранить Python stdlib, прежние версии и гарантии доставки. Основание: `.autopilot/2026-10-18-rich-media--wip/spec.md`, S1–S6, и `MEDIA-REFERENCE-ANALYSIS.md`.

## Решение

Расширить каноническую схему `video`, `media_group`, `quote` и структурными inline-узлами; прежние строки и image-блоки сохраняются. Группа содержит 2–50 image/video с `layout: collage|slideshow`; один файл остаётся leaf. Порядок и размещение перед/после текста сохраняются в версии. Отправка остаётся одним `sendRichMessage`, правка — `editMessageText` с прежним message_id. Локальные metadata в InputRichMessage не передаются.

MP4 ограничен 50 MiB, nonfragmented ISO-BMFF, H.264/AVC `avc1` и необязательным AAC `mp4a`. Структурно проверяются обязательные боксы, codec config, sample tables/timing/offsets и NAL envelopes; декодер кадров не реализуется. SHA256 и параметры проверяются повторно перед доставкой. Имеющийся настоящий синтетический base64 fixture не требует ffmpeg для работы проекта.

HTML сохраняет пропорции и порядок, даёт controls видео, паузу при навигации, ссылку на оригинал и доступную навигацию слайдов. MP4 отдаётся только из media по allowlist, с Range/HEAD. Коллаж считается приблизительным, custom emoji локально представлен доступным fallback без анимации. Unicode не нормализуется, custom ID задаётся явно; скрытой замены custom в API payload нет. Пользовательский HTML экранируется.

## Почему

Классические sendPhoto/sendMediaGroup/editMessageMedia не выбраны: пользователь подтвердил режим Rich Messages. Растеризация всех emoji и загрузка анимаций извне усложнили бы автономность и исказили бы отличие Unicode от custom. Pixel-perfect повтор мозаики одного клиента не даёт общей гарантии Telegram. Внешний видеоконвертер потребовал бы установки зависимостей; поэтому неподдерживаемые форматы отклоняются явно без изменения оригинала.

## Последствия

Часть корректных MP4 с другими кодеками/структурой будет отклоняться. Структурная валидация и browser-playback fixture — разные доказательства; они не равны проверке каждого кадра. Доступность custom emoji боту и вид в Telegram проверяются отдельно. Порядок, группировка, цитата и custom ID участвуют в версии и делают прежний review неактуальным. Неизменяемые версии, явное разрешение конкретного назначения, receipts/recovery и запрет повтора unknown сохраняются.
