# Controller Bot: результат ручной проверки

Дата: 18 октября 2026. Свидетельства — скриншоты пользователя в этой сессии, интерфейс Telegram Desktop. Это проверка конкретного сценария, не аудит кода Controller Bot.

## Настройка

Пользователь подключил отдельный канал «Тест отложенных постов» к Controller Bot через уже существующего `@DjEugeny_bot` (отображаемое имя «Секретарь»). Этот бот также используется для других каналов. Controller подтвердил успешное добавление канала. В редакторе выбран именно тестовый канал.

Локальный сервис переключён на того же бота: человек сохранил действующий токен скрытым `token-set`; `check` подтвердил бота, канал и право публикации. Это не создаёт интеграцию с очередью Controller Bot. Агент не читал токен или updates, не менял webhook, не отключал бота от других каналов.

## Наблюдения

| Действие пользователя | Наблюдаемый результат |
| --- | --- |
| Переслал существующий Rich Message с текстом, цитатой, коротким MP4 и тремя изображениями в выбранный редактор `@DjEugeny_bot` | Telegram показал пересланный материал, но «Предпросмотр» ответил «Нет сообщений для предпросмотра» (15:42) |
| Отправил обычный текст «Контрольный тест обычного текста» | Редактор принял текст; предпросмотр подтвердил 1 сообщение (16:52) |
| Переслал обычный текстовый пост «Проверка подключения» из тестового канала | Редактор принял пересылку; предпросмотр подтвердил 2 текстовых сообщения (16:54) |

Обычная работа редактора и пересылка обычного поста подтверждены. Проверенный Rich Message в редактор не добавлен. Поэтому этот путь нельзя предлагать как рабочую отложку нашего формата. Причина внутри Controller Bot неизвестна; неподдержка всех Rich Messages, ограничения конкретного блока/медиа и поведение других версий этим опытом не установлены.

## Что не проверено

Постановка Rich Message в очередь Controller и его выход при выключенном Mac не состоялись. Ни бесплатность будущего сценария, ни перенос/отмена, ни поддержка custom emoji не подтверждены. Вид пересланного сообщения у отправителя не доказывает приём редактором.

Контрольные сообщения не публиковались агентом. Пользователю предложено нажать «Отменить», но подтверждения закрытия черновика ещё нет. Не нажимать «Далее»/публикацию автоматически. Не удалять общего бота, не отзывать его токен, не отменять публикации других каналов.

Повторная проверка имеет смысл после заявленной поддержки Rich Messages или с другим явно согласованным сценарием. Критерий — сначала материал в предпросмотре редактора со всеми блоками, затем отдельное разрешение расписания и фактический выход в тестовом канале.
