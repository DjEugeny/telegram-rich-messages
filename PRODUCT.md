# Telegram Rich Messages

Пользователь без опыта программирования готовит, обсуждает и разрешает посты в чате с агентом. Локальные скрипты хранят версии, собирают автономное превью и отправляют Rich Markdown через Bot API. Отдельная модель не нужна.

**Текущая версия по решению пользователя 18 октября 2026 — без отложенных постов.** Расписание вынесено в `docs/ROADMAP.md`; проверка Controller Bot описана в `docs/controller-bot-check.md`. Не нужны настройка direct messages, второй аккаунт или хостинг пользователя. Компьютер нужен во время непосредственной отправки. Прежние операции сохраняются как история эксперимента.

Главный сценарий: материал → оформление → проверка → публикация → результат. При первом запуске — вымышленный черновик без токена. Дашборд содержит «Пост» и «История»; календарь только для навигации.

Материал может содержать PNG/JPEG, MP4, коллажи и слайд-шоу с сохранённым порядком, отдельные цитаты, Unicode emoji и custom emoji с явным ID. По умолчанию новые медиа стоят перед текстом. Полный порядок задаётся каноническими блоками. Четыре дополнительные демонстрации `demo-media` созданы из собственных синтетических материалов, без копирования реальных постов; команды идемпотентны.

Превью сохраняет пропорции, даёт доступ к оригиналам, нативные controls видео и доступную навигацию по слайдам. Это приблизительный локальный вид: мозаика и custom emoji могут отличаться от Telegram. Анимация custom emoji локально не загружается. Отправляется один Rich Message; классический режим сообщений не входит в продукт.

Платформа: статический HTML, локальные CSS/JS; Python 3.11+ со стандартной библиотекой. macOS и Windows. Токен вводит человек скрыто. Все внешние изменения требуют явного поручения.

Изображения ограничены поддерживаемыми PNG/baseline JPEG до 10 MiB; видео — nonfragmented MP4 H.264/AVC с необязательным AAC до 50 MiB. Установка ffmpeg для запуска не нужна. Проверка контейнера не доказывает декодирование каждого кадра. Локальные проверки macOS/browser, mock API и непроверенные native Windows/live Telegram разделены в `HANDOFF.md`; поддержка платформы не означает завершённую проверку на ней.
