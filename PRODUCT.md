# Telegram Rich Messages

Пользователь без опыта программирования готовит, обсуждает и разрешает посты в чате с агентом. Локальные скрипты хранят версии, собирают автономное превью и отправляют Rich Markdown через Bot API. Отдельная модель не нужна.

Пользователь получает сервис как есть: агент помогает запустить его, подключить выбранные канал и бота, подготовить материал и опубликовать после разрешения. История разработки и планы не входят в первое знакомство. Инструкции подбираются по фактической среде человека, а не по компьютеру автора.

Главный сценарий: материал → оформление → проверка → публикация → результат. При первом запуске можно посмотреть необязательную временную демонстрацию через preview-demo или начать со своего материала. Демонстрация не наполняет рабочую историю; новая рабочая история пустая до первого сохранённого материала. Дашборд содержит «Пост» и «История»; календарь только для навигации.

Материал может содержать PNG/JPEG, MP4, коллажи и слайд-шоу с сохранённым порядком, отдельные цитаты, Unicode emoji и custom emoji с явным ID. По умолчанию новые медиа стоят перед текстом. Полный порядок задаётся каноническими блоками. Четыре дополнительные демонстрации `demo-media` созданы из собственных синтетических материалов, без копирования реальных постов; команды идемпотентны.

Превью сохраняет пропорции, даёт доступ к оригиналам, нативные controls видео и доступную навигацию по слайдам. Это приблизительный локальный вид: мозаика и custom emoji могут отличаться от Telegram. Анимация custom emoji локально не загружается. Отправляется один Rich Message; классический режим сообщений не входит в продукт.

Платформа: статический HTML, локальные CSS/JS; Python 3.11+ со стандартной библиотекой. macOS и Windows. Токен вводит человек скрыто. Все внешние изменения требуют явного поручения.

Изображения ограничены поддерживаемыми PNG/baseline JPEG до 10 MiB; видео — nonfragmented MP4 H.264/AVC с необязательным AAC до 50 MiB. Установка ffmpeg для запуска не нужна. Проверка контейнера не доказывает декодирование каждого кадра. Технические результаты и границы приёмки хранятся в docs/RELEASE-STATUS.md; конкретный рабочий канал проверяется при подключении пользователя.

Дизайн-система находится в DESIGN.md и .impeccable/design.json. Режим поверхности: Operate, спокойный читаемый русский интерфейс. Внешний проект автора не нужен для запуска.
