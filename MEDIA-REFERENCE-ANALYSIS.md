# Перенос наблюдений Telegram в локальный инструмент

18 октября 2026 года четыре публичных поста просмотрены root-агентом в реальном in-app browser через веб-ленту Telegram. Основание — видимый DOM/медиа и скриншоты из `.autopilot/2026-10-18-rich-media--wip/reference.md`. Bot API, токен и реальные отправки не использовались. Тексты и авторские изображения в продукт не копировались.

## Как это сохраняется

Порядок медиа и текста хранится в канонических блоках версии. Несколько CLI-вложений по умолчанию становятся `collage` перед текстом; повторяемые `--media`, `--image`, `--video` сохраняют общий порядок. `--media-position after` и полный `--blocks` дают явное другое размещение. `slideshow` и `separate` выбираются явно, по одному файлу используется image/video leaf. Образцы команд и JSON — в [examples/README.md](examples/README.md).

Пропорция сохраняется без автоматической обрезки. Мозаика HTML приблизительна: совпадение с конкретным клиентом Telegram пиксель в пиксель не обещается. Цитата становится semantic `blockquote` и Rich Markdown с `> ` по строкам. Подчёркивание задаётся узлом `underline`. Unicode сохраняется без нормализации. Custom emoji задаётся ID и fallback, локально отображается доступным символом без загрузки анимации; запрошенный custom не заменяется обычным emoji в payload автоматически.

`demo-media` создаёт собственные вымышленные аналоги четырёх структур. В смешанном примере три изображения 9:16 и встроенный ролик 96×160 (3:5), 1 s; это отдельный синтетический материал, а не копия референса. Демонстрационный custom ID `1234567890123456789` вымышленный. Повтор команды не меняет существующие версии.

## Что подтверждено проверками

На собственном синтетическом HTTP fixture root-агент проверил desktop 1280×720 и mobile 390×844: шесть портретов 4:5, одиночные 3:4 и 4:5, смешанную группу video+3 photo 9:16, media перед текстом, цитату, Unicode `👩🏽‍💻 ❤️ 🏳️‍🌈` и доступный custom fallback. У fixture другое настоящее H.264-видео 144×256, 4 s: фактически достигнуты `currentTime=4`, `ended=true`, после Home — 0, после повторного Space — `paused=false` и рост currentTime. Навигация слайдов кнопками/End, счётчик 3/3, пауза видео при уходе и fallback-ссылка при ошибке также проверены.

Это доказывает локальное поведение синтетических материалов. Оно не подтверждает внешний вид реальных сообщений, право бота использовать custom emoji или воспроизведение всех MP4. Native Windows, live Telegram, Keychain/DPAPI не проверялись. Новая file:// offline проверка для Rich Media не выполнена из-за policy; прежний baseline остаётся историческим. Storage denied проверен отдельно на HTTP fixture с getter localStorage в копии app.js. Полные факты и ограничения — в [HANDOFF.md](HANDOFF.md).
